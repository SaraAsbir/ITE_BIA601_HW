# مشروع: اختيار الميزات باستخدام الخوارزميات الجينية
BIA601 – الخوارزميات الذكية

================================================================

## نظرة عامة
يهدف هذا المشروع إلى استخدام الخوارزمية الجينية لحل مشكلة اختيار الميزات (Feature Selection) في مجموعات البيانات، 
وذلك لتحقيق:
- أعلى دقة ممكنة للنموذج.
- أقل عدد من الميزات (لتقليل overfitting وتحسين التفسير).
- مقارنة الأداء بين مجموعات بيانات مختلفة.
- (سيتم لاحقًا مقارنة الأداء مع الطرق التقليدية مثل Mutual Information و RFE من قبل الفريق)

================================================================

## هيكل المشروع

ITE_BIA601_HW/
├── data/
│   ├── sample_data.csv          ← بيانات سرطان الثدي (70 ميزة)
│   └── sample_data_iris.csv     ← بيانات زهور Iris (14 ميزة)
├── src/
│   └── ga_selector.py           ← الخوارزمية الجينية (النسخة المحسّنة)
├── prepare_data.py              ← إنشاء البيانات (سرطان الثدي + Iris)
├── test_ga.py                   ← اختبار الخوارزمية وعرض النتائج
└── README.md                    ← هذا الملف

================================================================

## المتطلبات

- Python 3.8 أو أحدث  
- المكتبات المطلوبة:

```bash
pip install pandas scikit-learn numpy matplotlib
```

================================================================

## كيفية التشغيل

### 1. إنشاء البيانات (اختياري-الملفات موجودة مسبقا)
```bash
python prepare_data.py
```

> سيُنشئ الملفين التاليين:
> - `data/sample_data.csv` ← 70 ميزة (سرطان الثدي + ضجيج)
> - `data/sample_data_iris.csv` ← 14 ميزة (Iris + ضجيج بسيط)

---

### 2. تشغيل الخوارزمية الجينية

لتجربة بيانات سرطان الثدي:
```bash
python test_ga.py
```

لتجربة بيانات زهور Iris:
```python
df = pd.read_csv("data/sample_data_iris.csv")
```

ثم شغّل:
```bash
python test_ga.py
```

---

## النتائج المتوقعة

### 🔹 مجموعة سرطان الثدي
- عدد العينات: 569  
- عدد الميزات بعد الإضافة: 70  
- عدد الميزات المختارة: تقريبًا 21–25  
- دقة النموذج (اللياقة): حوالي **0.95**  

### 🔹 مجموعة زهور Iris
- عدد العينات: 150  
- عدد الميزات بعد الإضافة: 14  
- عدد الميزات المختارة: **3 / 14**  
- دقة النموذج (اللياقة): **0.9602**

**مثال من الإخراج الفعلي:**
```
الجيل 49: أفضل لياقة = 0.9602 | عدد الميزات = 3

==================================================
أفضل حل :
- عدد الميزات المختارة: 3 / 14
- درجة اللياقة: 0.9602
- مؤشرات الميزات المختارة (أول 10): [2, 3, 5]
==================================================
```

================================================================

## ملاحظات

- الكود يستخدم خوارزمية جينية كاملة (Selection, Crossover, Mutation).
- تم تحسين المعاملات (POP_SIZE, ALPHA, NUM_GENERATIONS) لزيادة الدقة.
- الكود يدعم أي بيانات أخرى بصيغة CSV تحتوي على عمود `target`.

================================================================

## المراجع

- مثال من نظام (LMS) – مشكلة حقيبة الظهر.
- مجموعة بيانات سرطان الثدي: sklearn.datasets.load_breast_cancer
-  مجموعة بيانات الزهور       :sklearn.datasets.load_iris
- Scikit-learn Documentation: Feature Selection, Cross-Validation
