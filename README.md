# مشروع: اختيار الميزات باستخدام الخوارزميات الجينية
BIA601 – الخوارزميات الذكية

================================================================

## نظرة عامة
يهدف هذا المشروع إلى استخدام الخوارزمية الجينية لحل مشكلة اختيار الميزات (Feature Selection) في مجموعات البيانات الكبيرة، وذلك لتحقيق:
- أعلى دقة ممكنة للنموذج.
- أقل عدد من الميزات (لتقليل overfitting وتحسين التفسير).
- (سيتم لاحقًا مقارنة الأداء مع الطرق التقليدية مثل Mutual Information و RFE من قبل الفريق)

## كيفية التشغيل

1. إنشاء البيانات التجريبية (اختياري – الملف موجود مسبقًا)
   python prepare_data.py
   > يُنشئ ملف data/sample_data.csv يحتوي على:
   > - 30 ميزة حقيقية من مجموعة "سرطان الثدي"
   > - 40 ميزة عشوائية (ضجيج)
   > - عمود target للتصنيف

2. تشغيل الخوارزمية الجينية
   python test_ga.py

3. النتائج المتوقعة
   - عدد الميزات المختارة: ~15–25 من أصل 70.
   - دقة النموذج: ≥ 94%.
   - الميزات المختارة تكون من النطاق 0–29 (أي الميزات الحقيقية فقط).
